EOR Scope for AI assistants

EOR Scope tells an AI assistant what an employee costs the employer in another country, before any Employer of Record (EOR) fee. It is a remote server of the Model Context Protocol (MCP), read-only, with no account and no authentication.

Server URL: https://mcp.eorscope.com/mcp (Streamable HTTP, POST).

What it answers

  • The statutory employer cost of a gross salary in one country, line by line: each employer contribution with its rate, base, ceiling or floor, source (official wherever one exists) and check date, then the monthly and annual total.
  • The same salary in several countries, or job offers with a different salary in each country.
  • The highest gross salary a total hiring budget allows.
  • A check of an EOR, PEO or payroll quote: the statutory employer charges it should contain, and what is left on top.
  • The cost of an EOR, an own entity or contractors over several years, from the fees the user supplies.
  • Leave, public holidays, notice, probation and the statutory number of salary payments (13th and 14th month).
  • Exchange-rate stress, the contractor day rate that costs the same as an employee, and enacted or announced changes to employer contributions with their effective dates.

A salary can be annual or monthly. A monthly salary is converted with the statutory number of payments of the country where it is tracked (14 in Portugal, for example); elsewhere the answer says it computed 12 payments and how to change that.

Try it

  • "How much does it cost the employer to hire a software engineer in Germany on 80,000 euros a year?"
  • "Here is my EOR quote for an employee in Spain on EUR 48,000 a year paid in 12 instalments: salary 4,000 EUR, employer social security 1,250 EUR and a service fee of 599 EUR per month. How much of it is statutory?"
  • "I have a total budget of 100,000 euros a year to hire someone in Germany. What is the highest gross salary I can offer?"
  • "Are employer social insurance contributions in Ireland going to change next year?"

Add it to an assistant

  • ChatGPT: Settings, Plugins, Add, "Create a custom MCP server", server URL above, authentication None (developer mode).
  • Claude (claude.ai, Desktop): Settings, Connectors, Add custom connector, paste the server URL, leave OAuth empty. Claude Code: claude mcp add --transport http eorscope https://mcp.eorscope.com/mcp.
  • Mistral Le Chat: Connectors, Add Connector, Custom MCP Connector, name eorscope, the server URL.
  • Perplexity (plans with custom connectors): Account settings, Connectors, Custom connector, Remote, the server URL, authentication None, transport Streamable HTTP.
  • Any other MCP client: the server URL above, Streamable HTTP, no authentication.

Data

76 countries. Employer contributions come from each country's administration (social security, tax or labour authority) wherever it publishes them; a line that rests on a secondary source says so. Exchange rates are official and dated. Each answer gives the snapshot date and each line its check date. Countries where dated changes have not been researched yet answer "not yet tracked", which does not mean nothing is scheduled. Methodology: eorscope.com/methodology. Limits

  • No provider prices: any EOR fee, entity cost or contractor fee in an answer is the one the user supplied.
  • Cost comparison, not legal, tax or employment advice. It does not compute net pay or income tax, and it does not classify workers.
  • Read-only: it hires, pays and contacts no one.
