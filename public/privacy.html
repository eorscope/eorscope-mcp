What the server receives

When your assistant calls an EOR Scope tool, it sends the server the arguments of that tool and nothing else: a country, a gross salary or a budget and their currency, a headcount, a date, an exchange-rate move, fees or costs you typed, and, for a quote check, the label and amount of each quote line. The server does not receive your conversation as such: it receives what the assistant chooses to pass as tool arguments. The assistant may also attach technical metadata to a call (for example the language or an approximate region); the server does not use, store or log it. The server does not ask for your name, your email address or your account with the assistant.

Do not put personal data in these arguments (for example a candidate's name in a quote line label): the tools do not need it.

What the server does with it

It computes the answer from the dated dataset bundled with the server and returns it. There is no account, no sign-in, no cookie and no database. The server is stateless: it does not store the arguments it receives or the answers it returns, and its code does not write them to any log. The widgets (the ledger and comparison cards) make no network request of their own.

Technical logs kept by the host

The server runs on Vercel. To deliver and protect the service, Vercel records technical request data such as the IP address of the caller, the date and time, the path requested (/mcp) and the response status. Requests come from the servers of the AI assistant you use, so the IP address in these logs is normally that assistant's, not your device's. We use these logs only to keep the service running and to investigate errors or abuse. They are kept for the period Vercel applies to the account; we do not export or keep copies.

Links to eorscope.com

Answers contain links to pages of eorscope.com, tagged utm_source=chatgpt so the website can count visits that come from an assistant. If you open one, the website's own notice applies: it sets no analytics cookie unless you accept it.

Your choices and rights

You can disable or remove the plugin in your assistant at any time. You may ask to access, correct or erase data about you, or object to its use, by writing to research@eorscope.com; as the server keeps no tool arguments, there is usually nothing tied to you to retrieve. You may also complain to the CNIL (cnil.fr).
